# Egocentrism in Strategic Decisions

Research code, data, and materials. Participants completed a Qualtrics survey with the Pods-and-Dots game (`interface/`) embedded in an iframe, and the game passed a JSON log of each participant's rounds back to Qualtrics. `analysis/01_build.R` builds the analysis data from that log. The data file is restricted to the 246 participants in the analysis sample.

```
data/
  qualtrics_data.csv       survey responses + game log (participant IDs replaced with random IDs)
analysis/                  run from the repo root, in order
  01_build.R               -> data/built/round_level_data.csv, participant_level_data.csv
  02_tables.R              LaTeX tables
  03_figures.R             Figures 2-6 and Supplementary Figures 1-14
  numbers.R                -> tables_and_charts/numbers_check.md (every statistic in the text)
  fig1_interface.py        Figure 1
tables_and_charts/
  main/                    main text and Supplementary Sections 1-5 and 8
  pass_comps/              Supplementary Section 6 (passed all comprehension checks on first try)
  exclude_early/           Supplementary Section 7 (excludes rounds 1, 2, 13, and 14)
interface/                 the game (Flask)
```

Output files are named after the figure or table they produce (`fig4_hetero.png` is Figure 4, `supp_table5_moderation_within.tex` is Supplementary Table 5). `fig4_hetero_blank.png` is Figure 4 without data points, for presentations. Supplementary Table 7 (cognitive reflection and numeracy items) and Supplementary Figures 15-20 (screenshots of the interface) are not generated by code.

## Requirements

Tested with these versions:

- **R 4.5.2**, with packages tidyverse 2.0.0, fixest 0.13.2, janitor 2.2.1, jsonlite 2.0.0, gridExtra 2.3, patchwork 1.3.2
- **Python 3.14**, with matplotlib 3.10.8 (Figure 1) and Flask 3.1.2 (the game; `interface/requirements.txt`)

```
install.packages(c("tidyverse", "fixest", "janitor", "jsonlite", "gridExtra", "patchwork"))
pip install matplotlib -r interface/requirements.txt
```

## Reproducing the results

```
Rscript analysis/01_build.R
Rscript analysis/02_tables.R
Rscript analysis/03_figures.R
Rscript analysis/numbers.R
python  analysis/fig1_interface.py
```

## The experimental interface (game)

To play locally, double-click `interface/run_interface_locally.bat` (Windows). It starts the game and opens it in your browser inside a fixed-size frame, as in the Qualtrics survey; close the terminal window to stop. Responses are saved to `interface/data/`. Rounds are drawn from `interface/stimuli/`, which `interface/generate_stimuli.R` generates. To run the game in a survey, host `interface/` on any web server with persistent storage and embed its URL in an iframe.
